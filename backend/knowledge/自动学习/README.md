# `backend/knowledge/自动学习/` —— 自动沉淀的问答记录

> **本目录只提交这个 README，记录一律不入库。**
> 这是仅次于 `data/uploads/` 的第二个隐私高风险目录。

## 里面放什么

系统把每轮「有价值的问答」自动写成 Markdown 留档，供后续复查与知识库扩充，典型结构：

```
自动学习/
└── 问答记录/
    └── 2026-11-12.md      # 按日期分文件，每次追加
```

每条记录含：用户原始提问、会话 `thread_id`、生成答案、涉及的库表名。
写入逻辑见 `backend/services/knowledge/knowledge_learning.py`。

## 为什么不能提交

- **提问原文**最危险：用户会直接贴公司名、客户名、订单号、金额、内网地址。
- 会话 ID 可与 `conversations.json` 反查，等于把整段上下文串起来。
- 即便是测试阶段的记录，也可能残留真实业务片段。

`.gitignore` 已排除 `backend/knowledge/自动学习/*`，只保留本 README。

## 想保留又不想泄露怎么办

| 需求 | 做法 |
|---|---|
| 换机器保留历史 | 整目录压缩后走内网网盘，不进 Git |
| 想对外展示能力 | 手工挑几条，**重写为示例**（换掉所有专名与数字）后放进 `backend/knowledge/` 根目录，那里是入库的 |
| 关闭自动沉淀 | 见 `knowledge_learning.py` 的开关，关闭后本目录不再增长 |
