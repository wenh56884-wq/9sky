# `backend/knowledge/uploads/` —— 知识库文档上传暂存区

> **本目录只提交这个 README，上传的文档一律不入库。**

## 里面放什么

用户在「知识库」页面拖入的 `.md` / `.txt` / `.pdf` 文档的**原始副本**。
真正参与检索的是 `backend/data/vector.sqlite3` 里的向量索引，本目录只是留档与重建来源。

## 为什么不入库

- 知识库文档通常是**企业内部制度、产品手册、FAQ、客户资料**，属租户私有内容。
- 公开仓库会让租户的运营细节被外部检索到。

`.gitignore` 已排除本目录内容。

## 与 `backend/knowledge/*.md` 的区别（容易混）

| 位置 | 性质 | 是否入库 |
|---|---|---|
| `backend/knowledge/*.md` | 项目自带的**示例知识库**（差旅报销政策、三个业务库的 NL→SQL 题库） | **入库**，不含真实记录值 |
| `backend/knowledge/uploads/` | 租户上传的**真实文档** | **不入库** |
| `backend/knowledge/自动学习/` | 系统自动沉淀的问答记录 | **不入库** |
